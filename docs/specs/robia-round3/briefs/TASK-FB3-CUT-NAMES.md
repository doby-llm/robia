# TASK-FB3-CUT-NAMES — Cutout methods Standard, Precise, Automatic

## Goal
ui3 F30 (REQ-FB-30, R3-DEC-065). The cutout settings reference "Precise" ("Precise cutout" pack card, "Needs precise cutout", the Automatic help) but the method list has only Standard and Automatic. Offer three clear methods and make the word "Precise" mean one thing.

## Files

## Steps
1. **Enum.** `enum class CutoutEngineChoice { Automatic, Standard, Precise }` (append; the stored names are the enum names, so `Automatic` and `Standard` keep their values and need no migration). `Preferences.cutoutEngineChoice()` still maps an unknown stored name to Automatic. `migratedCutoutEngine` is unchanged. Update the KDoc: Standard = ML Kit; Precise = the precise engine, needs the pack; Automatic = Precise when the pack is ready, else Standard.
2. **Behaviour.** `cutoutOptionsOf`: `usePrecise = useEnginePrecise(packReady, settings.cutoutEngine != CutoutEngineChoice.Standard)`. `RobiaSettings.preciseCutoutEnabled` = `cutoutEngine != Standard` (the developer switch reads on for Precise and Automatic; `setPreciseCutoutEnabled(true)` still writes Automatic). Once the pack is ready Precise and Automatic run the same engine; the fallback to ML Kit on a failed, rejected or timed-out photo is unchanged (`CutoutEngineRegistry`). Say this plainly in the receipt (R3-DEC-065).
3. **Hanger options.** `cutoutHangerOptionsAvailable(packReady, engine)` = `packReady && engine != Standard`; `hangerDetectionVisible` follows.
4. **Settings UI** (`PreciseCutoutSettings.kt`): the method dialog lists Standard, Precise, Automatic (this order), each with its one-line help (`supportingOf`: `cutout_method_standard_hint`, `cutout_method_precise_hint`, `cutout_method_automatic_hint`); Precise and Automatic keep the "Experimental" suffix (`cutoutMethodExperimentalRes` returns the label for both, null for Standard). A pure `cutoutMethodSelectable(option, current, packReady)`: Precise only when the pack is ready or it is the stored method; Standard and Automatic always. `CutoutChoiceDialog` gets an `enabledOf` parameter (default true) and a disabled option looks and behaves disabled. The method row's help follows the stored method (three helps) and, while the stored method is Precise or Automatic, the existing `cutout_method_experimental_hint` sentence is shown under it. `CutoutEngineChoice.labelRes()` gets `Precise`.
5. **Strings** (block `<!-- FB3-CUT-NAMES -->`; the existing keys are changed in place where noted). New: `cutout_method_precise` "Precise" | "Preciso" | "Präzise"; `cutout_method_precise_hint` "Best for hangers and similar-coloured backgrounds. Slower. Needs the cutout pack." | "Ideal con perchas o fondos parecidos. Más lento. Necesita el paquete de recorte." | "Am besten bei Bügeln oder ähnlichem Hintergrund. Langsamer. Braucht das Zuschnitt-Paket." Changed: `cutout_method_standard_hint` "Fast. Works for most photos. Does not remove hangers." | "Rápido. Sirve para la mayoría de fotos. No quita perchas." | "Schnell. Passt für die meisten Fotos. Entfernt keine Bügel."; `cutout_method_automatic_hint` "Uses Precise when the pack is downloaded, otherwise Standard." | "Usa Preciso si el paquete está descargado; si no, Estándar." | "Nutzt Präzise, wenn das Paket geladen ist, sonst Standard."; `cutout_needs_precise` "Needs Precise or Automatic and the cutout pack" (write ES and DE; list them in the receipt); `precise_cutout_title` "Cutout pack" | "Paquete de recorte" | "Zuschnitt-Paket", and `precise_cutout_body` starts with "Needed by Precise and Automatic." (ES/DE by you). `cutout_method_automatic` ("Automatic", "Automático", "Automatisch") and `cutout_method_standard` ("Standard", "Estándar", "Standard") stay. Grep the three EN/ES/DE files for any other "precise cutout" / "recorte preciso" / "präziser Zuschnitt" that names the pack or the method in the settings screens and reword it; the editor's `redo_cutout_*` strings already say Standard / Precise and stay.
6. **Tests.** `CutoutOptionsTest`: `usePrecise` over the three methods × pack ready / not (Standard never; Precise and Automatic only with the pack); stored names round-trip, unknown → Automatic; the legacy-boolean rows unchanged; `preciseCutoutEnabled` for each method. `SettingsMappingTest`: the K00 migration rows unchanged. `PreciseCutoutSettingsTest`: Experimental label for Precise and Automatic, none for Standard (replaces V-K00-2's wording, equal strength); `cutoutMethodSelectable`; `hangerDetectionVisible` for Precise. `CutoutHangerOptionsTest`: Precise with a ready pack → available. A strings test for the keys above in three locales.
